# BananaVision AI API

Consulta el [README principal](../README.md) para instalación, uso, límites, pruebas y evaluación.

La API sirve también el frontend. Desde el entorno virtual:

```bash
python run.py
```

Modelo incluido: `model/banana.keras`, Keras 3 compatible. No requiere tensorflowjs ni conversión durante la instalación. Copia `.env.example` a `.env` solo si necesitas cambiar configuración.
